# Competition Server — конкурс грантов

Учебный Java-проект по ТЗ «Конкурс грантов». Данные хранятся в памяти процесса; внешний HTTP-сервер не используется, вызовы выполняются через методы `Server`, а запросы/ответы представлены JSON-строками.

## Требования
- JDK 17 или новее.
- Maven (для стандартного жизненного цикла проекта); автоматические тесты можно запускать без Maven.

## Проверка
```sh
./scripts/test.sh
```

Скрипт компилирует production- и test-код с предупреждениями как ошибками и запускает интеграционные проверки.

## Реализовано в стартовом модуле
- `ServerResponse` с кодами `200`/`400` и JSON-ответом.
- Многослойная основа: `server`, `service`, `model`, `database`, `util`.
- Регистрация участника и эксперта, проверка уникальности логина и базовая валидация.
- Вход с уникальным UUID-токеном, выход, удаление аккаунта и инвалидирование его сессий.
- Singleton-хранилище в оперативной памяти.
- Интеграционные тесты позитивных и негативных сценариев.

## JSON-примеры
Участник: `{"fullName":"Иван Иванов","companyName":"Ромашка","login":"ivan","password":"Password1"}`

Эксперт: `{"fullName":"Анна Иванова","directions":["ИТ","Наука"],"login":"expert","password":"Password2"}`

Вход: `{"login":"ivan","password":"Password1"}`

> Пароли в этой учебной версии хранятся в памяти в открытом виде; для реального сервиса необходимы хеширование паролей и дополнительные меры безопасности.
